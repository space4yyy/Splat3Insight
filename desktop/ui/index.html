网络代理

应用内的 Nintendo 账号认证、SplatNet 数据和资源图片请求会使用此代理。外部浏览器中的登录页面仍按浏览器自己的网络设置访问。

支持 HTTP 或 HTTPS 代理，例如本机代理软件提供的 HTTP / 混合端口。SOCKS 暂不支持；地址中不要填写用户名或密码。测试只检查代理主机的 TCP 端口是否可连接，不会访问 Nintendo 服务。关闭自定义代理后，沿用应用原有网络环境设置。

在后台继续运行？

隐藏主界面后，OBS 服务和数据同步会继续运行。之后可从Dock图标重新打开，或选择退出应用。

删除账号

会移除这个账号的登录信息。本地的对战和打工记录默认保留，重新添加同一个账号后可以继续使用。

删除前建议先导出一份数据到本地，导出的文件不会被删除。

登录前请确认

登录 SplatNet 3 需要第三方服务 nxapi 生成登录参数。继续后，你的 Nintendo 账号 id_token、Nintendo Switch Online 应用接口（Coral）的令牌，以及和 Coral 收发的全部数据都会发送给 nxapi。了解 nxapi
