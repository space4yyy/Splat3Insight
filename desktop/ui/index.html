f 参数服务

Nintendo 登录成功后，获取 SplatNet token 还需要生成 f 参数。当前推荐 nxapi；它不使用 Nintendo 密码或 session token 作为 client id。

只填写 OAuth client id，不要填写 access token、session token 或 Nintendo id_token。
